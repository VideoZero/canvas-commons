# Layouts

<Fiddle mode="preview" ratio={'3'}>
  {layoutSource}
</Fiddle>

Layouts allow you to arrange your nodes using [Flexbox][flexbox]. Any node
extending the [`Layout`](/api/2d/components/Layout) node can become a part of
the layout. This includes, but is not limited to:
[`Rect`](/api/2d/components/Rect), [`Circle`](/api/2d/components/Circle), and
[`Img`](/api/2d/components/Img).

## Layout root

Layouts are an opt-in feature, meaning that they need to be enabled. It's done
by setting the [`layout`](/api/2d/components/Layout#layout) property on the Node
that we want to become the root of our layout:

<Tabs groupId="language" queryString>
<TabItem value="tsx" label="TSX">

```tsx
// ↓ layout root
<Rect layout>
  {/* ↓ layout child */}
  <Circle width={320} height={320} />
</Rect>
```

</TabItem>
<TabItem value="ts" label="TS">

```ts
// ↓ layout root
const rect = new Rect({
  layout: true,
  children: [
    // ↓ layout child
    new Circle({width: 320, height: 320}),
  ],
});
```

</TabItem>
</Tabs>

In the example above, we marked the `<Rect>` as the layout root. This will cause
the position and size of its descendants to be controlled by Flexbox (In this
case there's only one valid descendant: `<Circle>`). The layout root itself is
treated differently than its children - its size is controlled by Flexbox, but
the position stays unaffected.

:::info

Just setting the `layout` property doesn't always turn the node into a layout
root. If the node is already a part of the layout, it will be treated like the
rest of the descendants:

<Tabs groupId="language" queryString>
<TabItem value="tsx" label="TSX">

```tsx
// ↓ layout root
<Rect layout>
  {/* ↓ layout child, NOT a layout root */}
  <Rect layout>
    {/* ↓ layout child */}
    <Circle width={320} height={320} />
  </Rect>
</Rect>
```

</TabItem>
<TabItem value="ts" label="TS">

```ts
// ↓ layout root
const outerRect = new Rect({
  layout: true,
  children: [
    // ↓ layout child, NOT a layout root
    new Rect({
      layout: true,
      children: [
        // ↓ layout child
        new Circle({width: 320, height: 320}),
      ],
    }),
  ],
});
```

</TabItem>
</Tabs>

:::

## Cardinal directions

Layout nodes come with a set of helper properties that let you position them in
respect to their edges/corners. In the example below we use them to place two
squares on the left and right side of a gray rectangle. The yellow square is
positioned so that its right edge is in the same place as the left edge of the
rectangle. Meanwhile, the red square is placed so that its bottom left corner
aligns with the bottom right corner of the rectangle. All possible directions
include: [`middle`](/api/2d/components/Layout#middle),
[`top`](/api/2d/components/Layout#top),
[`bottom`](/api/2d/components/Layout#bottom),
[`left`](/api/2d/components/Layout#left),
[`right`](/api/2d/components/Layout#right),
[`topLeft`](/api/2d/components/Layout#topLeft),
[`topRight`](/api/2d/components/Layout#topRight),
[`bottomLeft`](/api/2d/components/Layout#bottomLeft), and
[`bottomRight`](/api/2d/components/Layout#bottomRight).

<Tabs groupId="language" queryString>
<TabItem value="tsx" label="TSX">

```tsx editor
import {makeScene2D, Rect} from '@canvas-commons/2d';
import {createRef} from '@canvas-commons/core';

export default makeScene2D(function* (view) {
  const rect = createRef<Rect>();

  view.add(
    <>
      <Rect
        ref={rect}
        width={200}
        height={100}
        rotation={-10}
        fill={'#333333'}
      />
      <Rect
        size={50}
        fill={'#e6a700'}
        rotation={rect().rotation}
        // Try changing "right" to "top"
        right={rect().left}
      />
      <Rect
        size={100}
        fill={'#e13238'}
        rotation={10}
        bottomLeft={rect().bottomRight}
      />
    </>,
  );

  yield* rect().rotation(10, 1).to(-10, 1);
});
```

</TabItem>
<TabItem value="ts" label="TS">

```ts editor
import {makeScene2D, Rect} from '@canvas-commons/2d';

export default makeScene2D(function* (view) {
  const rect = new Rect({
    width: 200,
    height: 100,
    rotation: -10,
    fill: '#333333',
  });

  const yellowRect = new Rect({
    size: 50,
    fill: '#e6a700',
    // Try changing "right" to "top"
  });

  const redRect = new Rect({
    size: 100,
    fill: '#e13238',
    rotation: 10,
  });

  view.add([rect, yellowRect, redRect]);

  // Position the yellow rect relative to the main rect
  yellowRect.rotation(rect.rotation);
  yellowRect.right(rect.left);

  // Position the red rect relative to the main rect
  redRect.bottomLeft(rect.bottomRight);

  yield* rect.rotation(10, 1).to(-10, 1);
});
```

## Groups

Nodes that don't extend the `Layout` class, such as the `Node` itself, are
unaffected by the layout and are treated as if they were never there. This lets
you apply filters and transformations to layout nodes without affecting the
hierarchy.

From the layout's perspective, all `<Rect>`s in the example below are siblings:

<Tabs groupId="language" queryString>
<TabItem value="tsx" label="TSX">

```tsx
<Layout direction={'column'} width={960} gap={40} layout>
  <Node opacity={0.1}>
    <Rect height={240} fill={'#ff6470'} />
    <Rect height={240} fill={'#ff6470'} />
  </Node>
  <Rect height={240} fill={'#ff6470'} />
</Layout>
```

</TabItem>
<TabItem value="ts" label="TS">

```ts
const layout = new Layout({
  direction: 'column',
  width: 960,
  gap: 40,
  layout: true,
  children: [
    new Node({
      opacity: 0.1,
      children: [
        new Rect({height: 240, fill: '#ff6470'}),
        new Rect({height: 240, fill: '#ff6470'}),
      ],
    }),
    new Rect({height: 240, fill: '#ff6470'}),
  ],
});
```

## Animated layouts

Changing the children of a layout makes its siblings jump to their new slots.
The methods below take an optional `duration` instead: the layout then reflows
smoothly and the call returns a generator to `yield*`. Without a duration they
behave like their [`Node`](/api/2d/components/Node) counterparts.

<Fiddle mode="preview" ratio={'1'} width={'1920'}>
  {layoutAnimationsSource}
</Fiddle>

### Adding and removing children

[`add`](/api/2d/components/Layout#add) and
[`insert`](/api/2d/components/Layout#insert) scale the new child into its slot
while its siblings make room. [`remove`](/api/2d/components/Layout#remove),
called on the child, scales it out while its siblings close the gap:

```tsx editor
import {Layout, Rect, makeScene2D} from '@canvas-commons/2d';
import {createRef, easeOutCubic} from '@canvas-commons/core';

export default makeScene2D(function* (view) {
  const row = createRef<Layout>();
  const card = createRef<Rect>();
  view.add(
    <Layout ref={row} layout direction="row" gap={20}>
      <Rect size={100} radius={12} fill={'#ff6470'} />
      <Rect size={100} radius={12} fill={'#ffc66d'} />
    </Layout>,
  );

  // Append at the end.
  yield* row().add(<Rect size={100} radius={12} fill={'#99c47a'} />, 0.6);
  // Insert at index 1.
  yield* row().insert(
    <Rect ref={card} size={100} radius={12} fill={'#68abdf'} />,
    1,
    0.6,
  );
  // Remove it again.
  yield* card().remove(0.6);

  // Replace the default scale animation with a fade.
  yield* row().add(
    <Rect size={100} radius={12} fill={'#b58fc2'} />,
    0.6,
    easeOutCubic,
    (node, duration, timing) => node.opacity(0).opacity(1, duration, timing),
  );
});
```

All three accept a timing function after the duration. The last argument
replaces the default scale animation: it receives the child, the duration and
the timing function, and returns the animation to play.

### Changing layout properties

[`editLayout`](/api/2d/components/Layout#editLayout) animates a batch of layout
property changes, such as `direction`, `wrap`, `gap` or `alignItems`. The
callback receives the layout to change, and the children glide from their old
positions to the new ones:

```tsx editor
import {Layout, Rect, makeScene2D} from '@canvas-commons/2d';
import {createRef} from '@canvas-commons/core';

export default makeScene2D(function* (view) {
  const list = createRef<Layout>();
  view.add(
    <Layout ref={list} layout direction="row" gap={20} alignItems="start">
      <Rect size={100} radius={12} fill={'#ff6470'} />
      <Rect size={140} radius={12} fill={'#ffc66d'} />
      <Rect size={80} radius={12} fill={'#99c47a'} />
    </Layout>,
  );

  yield* list().editLayout(0.6, layout => {
    layout.direction('column');
    layout.alignItems('end');
  });
  yield* list().editLayout(0.6, layout => {
    layout.direction('row');
    layout.alignItems('center');
  });
});
```

### Moving children between layouts

[`transitionTo`](/api/2d/components/Layout#transitionTo) moves a node into
another parent. The node travels to its new slot while the old slot closes and
the new one opens. Pass an index before the duration to choose the slot,
otherwise the node goes last.

### Taking children out of the layout

[`freezeLayout`](/api/2d/components/Layout#freezeLayout) pins each child at its
current position and stops the layout from placing them, so you can animate them
freely. [`thawLayout`](/api/2d/components/Layout#thawLayout) hands them back,
gliding each one to the slot the layout gives it:

```tsx editor
import {Layout, Rect, makeScene2D} from '@canvas-commons/2d';
import {all, createRef} from '@canvas-commons/core';

export default makeScene2D(function* (view) {
  const top = createRef<Layout>();
  const bottom = createRef<Layout>();
  const item = createRef<Rect>();
  view.add(
    <Layout layout direction="column" gap={60} alignItems="center">
      <Layout ref={top} layout gap={20} height={100}>
        <Rect ref={item} size={100} radius={12} fill={'#ff6470'} />
        <Rect size={100} radius={12} fill={'#ffc66d'} />
      </Layout>
      <Layout ref={bottom} layout gap={20} height={100}>
        <Rect size={100} radius={12} fill={'#99c47a'} />
        <Rect size={100} radius={12} fill={'#68abdf'} />
      </Layout>
    </Layout>,
  );

  // Move the red square to the start of the bottom row.
  yield* item().transitionTo(bottom(), 0, 0.6);

  // Scatter the bottom row, then let the layout gather it again.
  bottom().freezeLayout();
  yield* all(
    ...bottom()
      .children()
      .map((child, i) => child.position.y((i - 1) * 80, 0.6)),
  );
  yield* bottom().thawLayout(0.6);
});
```
