# Layouts

<AnimationPlayer name="layout" banner />

Layouts allow you to arrange your nodes using [Flexbox][flexbox]. Any node
extending the [`Layout`](/api/2d/components/Layout) node can become a part of
the layout. This includes, but is not limited to:
[`Rect`](/api/2d/components/Rect), [`Circle`](/api/2d/components/Circle), and
[`Img`](/api/2d/components/Img).

## Layout root

Layouts are an opt-in feature, meaning that they need to be enabled. It's done
by setting the [`layout`](/api/2d/components/Layout#layout) property on the Node
that we want to become the root of our layout:

```tsx
// ↓ layout root
<Rect layout>
  {/* ↓ layout child */}
  <Circle width={320} height={320} />
</Rect>
```

In the example above, we marked the `<Rect>` as the layout root. This will cause
the position and size of its descendants to be controlled by Flexbox (In this
case there's only one valid descendant: `<Circle>`). The layout root itself is
treated differently than its children - its size is controlled by Flexbox, but
the position stays unaffected.

:::info

Just setting the `layout` property doesn't always turn the node into a layout
root. If the node is already a part of the layout, it will be treated like the
rest of the descendants:

```tsx
// ↓ layout root
<Rect layout>
  {/* ↓ layout child, NOT a layout root */}
  <Rect layout>
    {/* ↓ layout child */}
    <Circle width={320} height={320} />
  </Rect>
</Rect>
```

:::

## Cardinal directions

Layout nodes come with a set of helper properties that let you position them in
respect to their edges/corners. In the example below we use them to place two
squares on the left and right side of a gray rectangle. The yellow square is
positioned so that its right edge is in the same place as the left edge of the
rectangle. Meanwhile, the red square is placed so that its bottom left corner
aligns with the bottom right corner of the rectangle. All possible directions
include: [`middle`](/api/2d/components/Layout#middle),
[`top`](/api/2d/components/Layout#top),
[`bottom`](/api/2d/components/Layout#bottom),
[`left`](/api/2d/components/Layout#left),
[`right`](/api/2d/components/Layout#right),
[`topLeft`](/api/2d/components/Layout#topLeft),
[`topRight`](/api/2d/components/Layout#topRight),
[`bottomLeft`](/api/2d/components/Layout#bottomLeft), and
[`bottomRight`](/api/2d/components/Layout#bottomRight).

```tsx editor
import {makeScene2D, Rect} from '@motion-canvas/2d';
import {createRef} from '@motion-canvas/core';

export default makeScene2D(function* (view) {
  const rect = createRef<Rect>();

  view.add(
    <>
      <Rect
        ref={rect}
        width={200}
        height={100}
        rotation={-10}
        fill={'#333333'}
      />
      <Rect
        size={50}
        fill={'#e6a700'}
        rotation={rect().rotation}
        // Try changing "right" to "top"
        right={rect().left}
      />
      <Rect
        size={100}
        fill={'#e13238'}
        rotation={10}
        bottomLeft={rect().bottomRight}
      />
    </>,
  );

  yield* rect().rotation(10, 1).to(-10, 1);
});
```

## Groups

Nodes that don't extend the `Layout` class, such as the `Node` itself, are
unaffected by the layout and are treated as if they were never there. This lets
you apply filters and transformations to layout nodes without affecting the
hierarchy.

From the layout's perspective, all `<Rect>`s in the example below are siblings:

```tsx
<Layout direction={'column'} width={960} gap={40} layout>
  <Node opacity={0.1}>
    <Rect height={240} fill={'#ff6470'} />
    <Rect height={240} fill={'#ff6470'} />
  </Node>
  <Rect height={240} fill={'#ff6470'} />
</Layout>
```

## Animated layouts

<AnimationPlayer name="layout-animated" small />

Layout containers support smooth FLIP-based animations for adding, removing,
and reordering children. Instead of elements snapping to their new positions,
they glide there smoothly.

### Adding and removing children

Use [`addAnimated`](/api/2d/components/Layout#addAnimated) and
[`removeAnimated`](/api/2d/components/Layout#removeAnimated) to animate
children entering and leaving the layout:

```tsx editor
import {Layout, Rect, Txt, makeScene2D} from '@motion-canvas/2d';
import {createRef, waitFor} from '@motion-canvas/core';

function card(text: string, color: string) {
  return (
    <Rect
      size={100}
      radius={12}
      fill={color}
      layout
      alignItems={'center'}
      justifyContent={'center'}
    >
      <Txt text={text} fill={'#fff'} fontSize={36} fontWeight={700} fontFamily={'monospace'} />
    </Rect>
  );
}

export default makeScene2D(function* (view) {
  const row = createRef<Layout>();
  view.add(
    <Layout ref={row} layout direction={'row'} gap={20}>
      {card('A', '#e13238')}
      {card('B', '#e8a631')}
    </Layout>,
  );

  yield* waitFor(0.5);

  // New element scales in while siblings slide over
  yield* row().addAnimated(card('C', '#41a663'), 0.5);
  yield* waitFor(0.5);

  // Element scales out while siblings close the gap
  yield* row().removeAnimated(row().children()[1] as Layout, 0.5);
  yield* waitFor(0.5);
});
```

You can also insert at a specific index with
[`insertAnimated`](/api/2d/components/Layout#insertAnimated):

```tsx
yield* row().insertAnimated(card('X', '#3b82f6'), 0, 0.5);
```

### Reordering children

Use [`reorderAnimated`](/api/2d/components/Layout#reorderAnimated) to
smoothly rearrange existing children:

```tsx editor
import {Layout, Rect, Txt, makeScene2D} from '@motion-canvas/2d';
import {createRef, easeInOutCubic, waitFor} from '@motion-canvas/core';

export default makeScene2D(function* (view) {
  const row = createRef<Layout>();
  const colors = ['#e13238', '#e8a631', '#41a663', '#3b82f6'];
  view.add(
    <Layout ref={row} layout direction={'row'} gap={20}>
      {colors.map((c, i) => (
        <Rect size={100} radius={12} fill={c} layout alignItems={'center'} justifyContent={'center'}>
          <Txt text={`${i + 1}`} fill={'#fff'} fontSize={36} fontWeight={700} fontFamily={'monospace'} />
        </Rect>
      ))}
    </Layout>,
  );

  yield* waitFor(0.5);

  // Reverse the order
  const children = row().children();
  yield* row().reorderAnimated([...children].reverse(), 0.6, easeInOutCubic);

  // Swap first and last
  yield* waitFor(0.5);
  const items = row().children();
  const swapped = [...items];
  swapped[0] = items[items.length - 1];
  swapped[items.length - 1] = items[0];
  yield* row().reorderAnimated(swapped, 0.6, easeInOutCubic);

  yield* waitFor(0.5);
});
```

### Animating layout changes with FLIP

For arbitrary layout property changes — like switching direction, toggling wrap,
or enabling flex-grow — use
[`recordFlipState`](/api/2d/components/Layout#recordFlipState) and
[`tweenFlip`](/api/2d/components/Layout#tweenFlip):

```tsx editor
import {Layout, Rect, makeScene2D} from '@motion-canvas/2d';
import {createRef, waitFor} from '@motion-canvas/core';

export default makeScene2D(function* (view) {
  const container = createRef<Layout>();
  const colors = ['#e13238', '#e8a631', '#41a663', '#3b82f6'];
  view.add(
    <Layout ref={container} layout direction={'row'} gap={16}>
      {colors.map(c => <Rect size={80} radius={12} fill={c} />)}
    </Layout>,
  );

  yield* waitFor(0.5);

  // Snapshot positions, change layout, animate the transition
  const before = container().recordFlipState();
  container().direction('column');
  yield* container().tweenFlip(before, 0.8);

  yield* waitFor(0.5);

  // Switch back to row with wrap
  const before2 = container().recordFlipState();
  container().direction('row');
  container().wrap('wrap');
  container().width(200);
  yield* container().tweenFlip(before2, 0.8);

  yield* waitFor(0.5);
});
```

The FLIP (First, Last, Invert, Play) technique works by:

1. **`recordFlipState()`** — snapshot each node's position and size
2. Apply your layout changes (direction, wrap, grow, etc.)
3. **`tweenFlip()`** — snapshot the new state, then animate from old to new

By default, `recordFlipState()` walks up to the layout root and captures the
entire layout tree. Pass `false` to only capture the container and its
descendants.
